# Power Toys for Umbraco

[![Downloads](https://img.shields.io/nuget/dt/Umbraco.Community.PowerToys?color=cc9900)](https://www.nuget.org/packages/Umbraco.Community.PowerToys/)
[![NuGet](https://img.shields.io/nuget/vpre/Umbraco.Community.PowerToys?color=0273B3)](https://www.nuget.org/packages/Umbraco.Community.PowerToys)
[![GitHub license](https://img.shields.io/github/license/jumoo/umbraco.community.powertoys?color=8AB803)](https://github.com/jumoo/umbraco.community.powertoys/blob/v17/main/LICENSE)

A dashboard in the Umbraco Settings section for small, focused admin tools ("power toys"). Other
packages can add their own tools to the dashboard by registering against PowerToys' `powerToy`
backoffice extension type - no dependency on this package's code required.

![Power Toys dashboard](https://raw.githubusercontent.com/Jumoo/umbraco.community.powertoys/v17/main/docs/dashboard.png)
