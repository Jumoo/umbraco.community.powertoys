# Security Policy

## Supported versions

Umbraco Community PowerToys ships one release line per Umbraco major it targets. Fixes go to the
current line, and to the previous one where the issue is serious and the fix is practical.

| Version | Branch | Supported |
| --- | --- | --- |
| 0.x (Umbraco 17) | `main` | Yes |

## Reporting a vulnerability

Please **do not** open a public issue for a security problem.

Email **kevin@jumoo.co.uk** with a description of the issue, the version affected, and steps to
reproduce it. We'll acknowledge within a few working days and keep you updated as we work on it.
